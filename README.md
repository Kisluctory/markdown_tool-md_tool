# iRead · Markdown 阅读器 V1

一款轻量、零依赖的本地 Markdown 编辑器兼阅读器。打开本地 `.md` 文件，在「编辑源码 / 富文本预览」之间切换阅读与修改，并通过备份机制保护原文件不被误改。

## 功能特性

- **打开**：左上角「打开文件」按钮，UTF-8 优先、GB18030 自动回退
- **编辑 / 预览**：默认源码编辑，一键切换文本级富文本渲染（标题 / 加粗 / 斜体 / 删除线 / 行内代码 / 代码块 / 列表 / 引用 / 表格 / 分隔线 / 任务列表）
- **备份保护**：打开即自动备份到 `backups/`；「保存」只写备份，「快速保存」（需二次确认）才写原文件
- **备份管理**：左侧列表以 H1 大标题命名（无 H1 用文件名），支持选中编辑、删除、收起
- **视觉**：Win11 记事本风黑灰配色，无动画、仅点击反馈
- V1 不处理图片与超链接（原样保留为纯文本）

## 环境依赖

| 项 | 要求 |
|---|---|
| 操作系统 | Windows 7 / 10 / 11 |
| Python | 3.8+，**需含 tkinter**（官方 Windows 安装包默认自带） |
| 第三方库 | **无**，仅用标准库 |

> 已验证环境：Windows 11 + Python 3.13（tkinter 8.6）。

## 快速开始

### 方式一：源码直接运行

```bash
git clone <仓库地址>
cd iread_v_2
python main.py
```

或双击 `run.bat`。

### 方式二：打包为 exe（GitHub Release 发布）

```bash
pip install pyinstaller
pyinstaller --onefile --windowed --name iRead main.py
```

产物为 `dist/iRead.exe`，双击即可运行，目标机器无需安装 Python。

> 备份目录位置：源码运行时在项目根目录；打包为 exe 后在 `iRead.exe` 同级目录（自动判断）。

## 使用说明

1. 点「打开文件」选择 `.md`，内容以源码形式载入，并自动在 `backups/` 创建备份
2. 点「预览」查看富文本渲染，点「编辑」切回源码
3. 「保存」写入备份（原文件不变）；「快速保存」经二次确认写回原文件
4. 左侧列表点击条目即选中编辑；「删除选中」删除备份（不影响原文件）；「◀ 列表」收起/展开侧栏

```
├── gui.py               tkinter 界面与渲染

├── storage.py           纯逻辑：编码回退读取 / 备份管理
├── run.bat              双击启动脚本
├── PRD.md               产品需求文档
├── tests/               单元测试
└── backups/             运行时生成，存放备份（勿提交）
```
